# FIX-ORI-RN-003-2 — cycle-2 GREEN (corrected charter: remove `ring-*` from the conditional className)

## Verdict

`completed`. The corrected fix removes `ring-2` and `ring-ring/50` from InputGroup's focused
conditional `className` and expresses the 2px focus ring through a hoisted
`focusedStyle = { borderWidth: 2, borderColor: <ring at 0.5 alpha> }` (comma-form `hsla(...)`),
keeping `border-ring` (proven clean) and `dark:bg-input/30` (proven clean) as classes. The
nativewind native composer now renders and the send button is tappable on iOS AND Android in
light AND dark, with no uniwind/web regression.

## The change (registry source, `packages/registry/src/components/ui/input-group.tsx`)

```tsx
const focusedStyle = focused
  ? { borderColor: scheme === 'dark' ? 'hsla(300, 0%, 45%, 0.5)' : 'hsla(0, 0%, 63%, 0.5)', borderWidth: 2 }
  : undefined;
// className: 'flex-row items-center gap-2 rounded-md border border-input bg-background px-3',
//            'dark:bg-input/30',          ← stays a class (proven clean)
//            focused && 'border-ring',    ← ring-2 / ring-ring/50 REMOVED; border-ring stays
// style={focusedStyle}
```

The three hand-maintained copies (apps/harness `ui`, apps/harness `ui.nativewind`,
apps/example) were edited in lockstep and are byte-identical to the source after the
`@/registry/{engine}/` → `@/` rewrite. `public/r/{nativewind,uniwind}/input-group.json` were
regenerated by `pnpm registry:build`.
