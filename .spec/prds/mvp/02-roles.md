# Roles

Two audiences, and both matter: the **developers** installing components, and the **end
users** of the chat UI those developers ship. There is no server, no account, and no login
— this is a component registry.

| Role | Description |
|------|-------------|
| Ship-It Expo Developer | Solo or small-team app developer adding an AI chat screen to an existing Expo app |
| Design-System Owner | Front-end lead maintaining a themed RNR app with brand tokens and dark mode |
| Agent-App Builder | Developer shipping an agentic product (tool calls, approvals, plans) with a mobile client |
| Web-to-Mobile Porter | Developer with a shipping shadcn/AI Elements web app who now needs the mobile client |
| Chat End User on a Phone | The person actually using the AI app the developer ships |
| Registry Maintainer | Owner of the rnr-ai-elements repo and its CI merge gate |
