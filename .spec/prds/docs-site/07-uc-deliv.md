## UC-DELIV-01: Build the docs over fail-closed registry data

A prebuild enriches registry.json into registry-items.json behind hard gates, so missing or stale data is a build failure naming the item, never a silently degraded page.

- ☐ System fails the docs build when the enriched dataset does not contain exactly 56 items, naming the mismatching item in the error
- ☐ System fails the docs build when any files[].path is missing or empty, when a component's props type is unresolved, when family coverage is not exact, or when an Expo Go verdict is absent
- ☐ Maintainer can run the ordered CI chain (registry:build, gallery:manifest, docs build) so docs always build over artifacts provably in sync with the registry
- ☐ System keeps apps/docs/public/r generated-only and gitignored, regenerating it from packages/registry as the single source
- ☐ System fails the docs build on a broken internal link (link check over dist/) and on an authored snippet that does not typecheck against the real files it was extracted from [v1.1.0 TW-06]

## UC-DELIV-02: Deploy gated to Cloudflare Workers at the canonical domain

The static dist/ deploys as Cloudflare Workers static assets at the rnraielements.com apex, gated behind the existing quality jobs, with security headers, tiered caching, previews, and rollback.

- ☐ Maintainer can deploy the static dist/ as Cloudflare Workers static assets with the docs deploy job gated behind registry freshness, typecheck, lint, and test
- ☐ Visitor can reach the site at the apex rnraielements.com with www redirecting via a zone-level 301
- ☐ System serves HTML with must-revalidate, /_astro/* assets as immutable, and /r/*.json with short max-age caching, plus CSP, HSTS, nosniff, and frame-deny response headers
- ☐ Maintainer can open PR preview URLs through non-promoting version uploads and roll back a bad deploy instantly

## UC-DELIV-03: Serve the registry JSON from the same deploy

Install commands point at rnraielements.com because the registry JSON is served same-origin by the same deploy that serves the docs.

- ☐ Agent can fetch any registry item JSON from https://rnraielements.com/r/{engine}/{item}.json served by the same deploy as the docs
- ☐ System serves all 112 engine-item JSON files generated by the same CI chain that proves registry freshness
- ☐ Integrator can run an absolute-URL CLI add against the live domain and receive the correct React Native item JSON

---

## UC-DELIV-04: Recover from bad deploys and dead URLs

A styled 404 with search recovery, vanity redirects, and one-command rollback keep visitors and maintainers unblocked when things go wrong.

- ☐ Visitor can see a styled 404 page offering Cmd+K search recovery rather than a blank error
- ☐ Visitor can follow vanity redirects (/docs to /docs/introduction and /install to /docs/installation) as 301s
- ☐ Maintainer can roll back to the previous deploy with a single command because the Worker has no bindings blocking rollback
