## Background
Problem: nothing deploys the docs site from CI. Today a human runs wrangler by hand, so a red quality job or a stale registry tree can reach production unnoticed.

Why it matters: the deploy is the last hop of the delivery arc. It must run only after every quality job and both preflights pass, ship exactly the tested `dist`, and stamp the deploy with its commit so later proofs can tie live bytes to one commit.

Current: ci.yml has five jobs (typecheck, lint, test, registry, docs-e2e) and no deploy job.

Desired: a `deploy` job, push-to-main only, gated on all five jobs, that downloads `docs-dist`, runs `Preflight dist` and `Preflight edge`, then runs `wrangler deploy --message ${{ github.sha }}`.

## Critical Constraints
MUST:
- MUST gate deploy with `needs: [registry, typecheck, lint, test, docs-e2e]` and the push-to-main `if`, and MUST leave the gating expression free of any status-check override.
- MUST give the job `permissions: { contents: read }`, `environment: production`, and `concurrency: { group: docs-deploy, cancel-in-progress: false }`, and MUST pass CLOUDFLARE_API_TOKEN only as `${{ secrets.CLOUDFLARE_API_TOKEN }}` in the wrangler step's env.
- MUST order the steps exactly: `Download docs dist` (download-artifact name docs-dist, path apps/docs/dist), then `Preflight dist`, then `Preflight edge`, then cloudflare/wrangler-action with wranglerVersion '4.81.0', workingDirectory apps/docs, command `deploy --message ${{ github.sha }}`, then a curl smoke of `https://rnraielements.com/r/nativewind/conversation.json`.
- MUST pin every `uses:` in the job to a 40-hex commit SHA with a `# vX.Y.Z` comment, re-resolved at implementation time with `gh api repos/<owner>/<repo>/commits/<tag> --jq .sha` (the annotated v4.1.3 tag object of wrangler-action is not a commit).
NEVER:
- NEVER add a workflow_dispatch trigger or any other trigger to ci.yml, NEVER add `continue-on-error` in the job, and NEVER run a build command (registry:build, astro build, e2e:docs) inside deploy.
- NEVER edit apps/docs/wrangler.jsonc, _headers, _redirects or either preflight script, and NEVER print the token.
STRICTLY:
- STRICTLY treat these as human-owned preconditions, never hidden assumptions: the CLOUDFLARE_API_TOKEN repo secret, syncing local main (605 commits ahead) to GitHub through a PR, the `production` environment limited to main, the Cloudflare zone-edit token scope, and Sprint 05's ORI-CI-003 (ci.yml shape) and ORI-DEP-003 (accepted docs already published). APX-020's script checks the first three. Cross-sprint ids stay out of depends_on.
- STRICTLY prove the deploy behaviour on a real GitHub Actions run through APX-024 (primary owner of FLOW-DELIV-02-gated-deploy-order). This task's own tests prove the workflow file is correct before that run exists.

## Specification
Objective: Add the gated, commit-stamped deploy job to ci.yml so a push to main deploys the tested docs dist as Workers static assets only after every quality job and both preflights pass.
Success state: ci.yml passes actionlint and its deploy job matches the contract above with every action pin resolving on GitHub. The pinned wrangler accepts `deploy --message <sha>` in a dry run. The first real run is proven by APX-024 after the human preconditions.

Provides:
- Job id `deploy` in ci.yml, gated by needs: [registry, typecheck, lint, test, docs-e2e] and `if: github.event_name == 'push' && github.ref == 'refs/heads/main'`
- Job-level permissions contents: read only, environment production, concurrency group docs-deploy with cancel-in-progress false
- Step order: checkout, pnpm setup, node setup, frozen install, `Download docs dist`, `Preflight dist`, `Preflight edge`, wrangler-action, post-deploy smoke
- Deploy stamp: `wrangler deploy --message ${{ github.sha }}`, so the active version's workers/message is the 40-hex commit

Consumes:
- docs-dist artifact (APX-022)
- scripts/docs-deploy/preflight-dist.ts (astro APX-031, command `pnpm exec tsx scripts/docs-deploy/preflight-dist.ts --dist apps/docs/dist`)
- scripts/docs-deploy/preflight-edge.ts (cloudflare-workers APX-004, command `pnpm exec tsx scripts/docs-deploy/preflight-edge.ts --dist apps/docs/dist --require-www-redirect`, needs no secret)
- check-deploy-preconditions script (APX-020) for the human-owned secret, synced main and production environment
- apps/docs/wrangler.jsonc (assets.directory ./dist, custom domain)
- repo secret CLOUDFLARE_API_TOKEN (scope: Account Workers Scripts Edit + Account Settings Read; Zone Workers Routes Edit)

Boundary contracts:
- CAP-DEP-01 deploy hop: the job runs only after every needed job succeeded, ships the tested artifact, and stops before any upload if either preflight fails.
- The www gate: the shipped _headers carries HSTS with includeSubDomains, so `Preflight edge` runs with --require-www-redirect and a deploy can never precede the www 301.
- Deploy stamp seam: RNR's same-deploy proof (APX-040) reads workers/message and needs exactly one 40-hex SHA there. --tag is not used because it caps at 25 characters.

Capabilities: CAP-DEP-01. PRD refs: UC-DELIV-02 AC-1/2; 11-technical-requirements/01 posture; 11-technical-requirements/06 external deps; 11-technical-requirements/09 CAP-DEP-01.
