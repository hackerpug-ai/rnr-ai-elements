```ts
const show = (sha: string, p: string) => execFileSync('git', ['show', `${sha}:${p}`], { cwd: REPO_ROOT, encoding: 'utf8', maxBuffer: 64 << 20 });
const built = `${JSON.stringify(buildItem(item, engine, (p) => show(sha, p)), null, 2)}\n`;
```
Anti-pattern: Comparing the served hash to HEAD's committed public/r: it passes for every deploy since 2026-09-15, because conversation.json has not changed since ad650d36. Also: hardcoding HEAD's hashes, or turning a missing token into test.skip.
