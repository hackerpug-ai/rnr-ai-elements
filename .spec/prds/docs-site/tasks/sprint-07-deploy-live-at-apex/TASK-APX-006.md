## Background
Problem: the apex serves no delivery contract, and nothing asserts one. Every path returns `public, max-age=0, must-revalidate`, no security header is sent, and `www.rnraielements.com` does not resolve.
Why it matters: UC-DELIV-02 promises tiered caching, security headers and a www redirect. Without a live-origin spec, APX-001 and APX-002 have no RED to turn green, and Sprint 07 cannot prove its gate steps 5-7.
Current: only Sprint 05's `public-recovery.remote.spec.ts` lane exists for the public origin.
Desired: one shared live lane config and one RED-first spec that any later live spec reuses.

## Critical Constraints
MUST:
- MUST make `tests/sprint-07-deploy-live-at-apex/live.playwright.config.ts` exactly: one browserless project (no `devices` import), `testDir: '.'`, `testMatch: '**/*.remote.spec.ts'`, `workers: 1`, `retries: 0`, `timeout: 3_600_000`, `use.baseURL: 'https://rnraielements.com'`, and no `webServer` key
- MUST fetch every asserted URL with Playwright's `request.get(url, { maxRedirects: 0 })` against the literal origin `https://rnraielements.com` (and `https://www.rnraielements.com` for the redirect), so an unresolved host, a served 200 at www, or a comma-joined header value fails the test
- MUST title the flow test with the exact id `FLOW-DELIV-02-header-and-domain-contract` and record every request/response pair into evidence run.json; the RED run at landing is copied to proof.red before APX-001 or APX-002 change anything
- MUST set a tight per-test timeout (`test.setTimeout(60_000)`) on every header/redirect test, because the lane default of 60 minutes exists only for the real-CLI round trip
NEVER:
- NEVER stand up a fixture server, intercept a request, or stub Cloudflare: every assertion reads a real response from the live domain
- NEVER edit `playwright.config.ts`, `vitest.config.ts` or any Sprint 05 file: the root config's `testIgnore: '**/*.remote.spec.ts'` is what keeps CI's docs-e2e and vitest jobs off live network
- NEVER let APX-007 or APX-040 edit `live.playwright.config.ts`: this task is its sole owner and it is a never-edit path for them
- NEVER assert the 301 for a path other than `/docs/introduction` and `/`, and never weaken an assertion to make today's live apex pass
STRICTLY:
- STRICTLY the CSP asserted contains every directive of `default-src 'self'; script-src 'self' 'unsafe-inline' 'wasm-unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self' data:; connect-src 'self'` (the human-approved amendment that adds `'wasm-unsafe-eval'`)
- STRICTLY cache-control is compared as the whole header value and must equal one of the three tier strings exactly; a value containing a comma-joined repeat (e.g. two `max-age`) fails
- UNIT_TEST_JUSTIFIED: the header-oracle test AC-4 feeds literal header lists to the assertion helper and does no I/O, so a unit test is right because it proves the oracle rejects joined, duplicated and missing headers without needing a broken live server.
- PRECONDITION (human-owned, not a dependency): Sprint 05's ORI-DEP-003 publishes current docs to the apex. Until then `/docs/introduction` returns 404, which is one more honest RED reason; do not mask it
