# Quickstart builds a chat screen end to end

Follow /docs/quickstart as the only tutorial on the site. Pick an engine from the tabs, run the literal command `npx @react-native-reusables/cli@latest add https://rnraielements.com/r/nativewind/conversation.json` (or its /r/uniwind/conversation.json twin under the uniwind tab), then render a message list and prompt input following the tutorial code. Expected output: /docs/quickstart returns 200, every engine-varying code block is tabbed, both tab panels contain a complete runnable install command, the rendering code follows, and the conclusion links the worked example (apps/example wiring AI SDK v7 useChat).
