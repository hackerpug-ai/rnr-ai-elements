Released 2026-09-07. The initial release ships the complete registry: 56 universal AI chat and agent UI items for React Native, distributed as a copy-paste registry rather than an npm package. Every item is built once and fanned out to the nativewind and uniwind engine trees.

<!-- Deriving commit range: git log v0.1.0 — every commit from 5f13ec4a (init-project) through the v0.1.0 tag. -->

## Added

- The complete 56-item registry, installable through the RNR CLI by absolute HTTPS item URL, in both engine trees:
  - Conversation: [checkpoint](/components/checkpoint), [conversation](/components/conversation), [open-in-chat](/components/open-in-chat)
  - Message: [shimmer](/components/shimmer), [image](/components/image), [persona](/components/persona), [message](/components/message), [question](/components/question), [queue](/components/queue), [attachments](/components/attachments)

  - Reasoning: [reasoning](/components/reasoning), [task](/components/task), [agent](/components/agent), [chain-of-thought](/components/chain-of-thought), [plan](/components/plan), [confirmation](/components/confirmation), [context](/components/context)
  - Sources: [sources](/components/sources), [inline-citation](/components/inline-citation), [audio-player](/components/audio-player), [web-preview](/components/web-preview)
  - Suggestion: [suggestion](/components/suggestion)

- Registry self-referencing URLs pin to the release tag through the {version} token, so every engine tree installs against the release it shipped with.
