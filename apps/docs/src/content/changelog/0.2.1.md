Released 2026-09-08. Hotfix release: six registry items shipped without the sibling files their sources import, so installing them through the CLI produced a broken tree. This release completes those file sets.

## Added

none

## Changed

- The example app now installs the full 56-item set through the real RNR CLI, replacing the walking-skeleton subset from v0.1.0.

## Fixed

- Six items shipped without the sibling files their sources import — consumers got prompt-input.tsx referencing ./prompt-input.logic with no such file. [prompt-input](/components/prompt-input) now ships prompt-input.logic and attachments.logic, [agent](/components/agent) ships persona, [plan](/components/plan) ships task.logic, and [model-selector](/components/model-selector), [mic-selector](/components/mic-selector) and [voice-selector](/components/voice-selector) ship command.logic.
- The installed icon.tsx in the example app carried a usage comment pointing at a registry-internal path that does not exist in a consumer tree; the comment now shows the consumer alias.
